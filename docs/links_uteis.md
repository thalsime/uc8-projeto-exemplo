# Links úteis - UC8, Desenvolver aplicações mobile

Dois grupos: o site oficial de cada tecnologia da unidade, apontando para a versão em
português quando ela existe, e alguns links complementares de apoio. Todos foram abertos e
conferidos antes de entrar aqui.

## As tecnologias da unidade

| Tecnologia | Para que serve na unidade | Link | Idioma |
|---|---|---|---|
| Node.js | Executa JavaScript fora do navegador; roda o servidor de desenvolvimento | https://nodejs.org/pt-br (instalador em https://nodejs.org/pt-br/download) | português |
| npm e npx | `npm` instala pacotes; `npx` executa um pacote sem instalá-lo de vez | https://docs.npmjs.com/ | inglês |
| TypeScript | A linguagem do projeto | https://www.typescriptlang.org/pt/ (o manual completo segue em inglês: https://www.typescriptlang.org/docs/handbook/intro.html) | português e inglês |
| React | Componentes, props e estado; começa na web, no módulo 2 | https://pt-br.react.dev/learn | português |
| React Native | O mesmo modelo do React no celular, com componentes nativos; módulo 3 | https://reactnative.dev/docs/getting-started | inglês |
| Expo | Cria, executa e empacota o aplicativo React Native | https://docs.expo.dev/ | inglês |
| Expo Go | O aplicativo de celular que carrega o projeto do servidor de desenvolvimento | https://expo.dev/go (instalação pela Play Store: https://play.google.com/store/apps/details?id=host.exp.exponent&hl=pt_BR) | inglês e português |
| React Navigation | Navegação entre telas; módulo 4 | https://reactnavigation.org/docs/getting-started/ | inglês |
| expo-sqlite | Banco de dados no próprio aparelho; módulo 7 | https://docs.expo.dev/versions/latest/sdk/sqlite/ | inglês |
| EAS Build | Gera o APK na nuvem; módulo 9 | https://docs.expo.dev/build/introduction/ | inglês |
| Git | Versionamento local | https://git-scm.com/downloads/ (instalador); livro Pro Git traduzido: https://git-scm.com/book/pt-br/v2 | inglês e português |
| GitHub | Repositório remoto, obrigatório a partir do encontro 2 | https://docs.github.com/pt (documentação); cadastro em https://github.com/signup | português |
| Visual Studio Code | O editor | https://code.visualstudio.com/docs | inglês |
| platform-tools (`adb`) | Só no caminho USB: liga o celular ao computador pelo cabo | https://developer.android.com/tools/releases/platform-tools?hl=pt-br | português |
| BrasilAPI | API pública sem chave usada no projeto-exemplo; módulo 6 | https://brasilapi.com.br/docs | português |
